| Boundary | Description |
|----------|-------------|
| device runtime to Google OAuth token service | Authentication tokens cross from app runtime to external identity boundary. |
| local backup archive to Google Drive API | User data leaves device boundary and must use authenticated, validated transport. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-10 | S | GoogleDriveAuthClient token source | mitigate | Use OAuth-issued access tokens only and reject empty/expired tokens before API call. |
| T-11-11 | T | upload request payload | mitigate | Require archive path validation and provider-side checksum-compatible payload metadata. |
| T-11-12 | R | manual backup action auditing | mitigate | Persist success/failure metadata in settings and include deterministic error mapping for auth failures. |
</threat_model>
