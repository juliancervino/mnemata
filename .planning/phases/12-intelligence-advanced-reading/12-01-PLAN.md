| T-12-02 | T | provider response handling | mitigate | Enforce typed response parsing + deterministic error mapping before UI exposure. |
| T-12-03 | D | provider calls | mitigate | Add explicit timeout and bounded retries to prevent UI hangs. |
| T-12-04 | E | settings toggles | mitigate | Gate AI capability checks on key presence and explicit user-enabled toggles. |
