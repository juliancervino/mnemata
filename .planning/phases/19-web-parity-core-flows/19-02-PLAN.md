<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser URL/file input -> ingestion validation | Untrusted user content enters extraction and persistence pipeline. |
| Duplicate/open-existing action -> database lookup | User path selection influences whether existing or new records are opened/saved. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-02-01 | T | URL/file intake | mitigate | Validate URL schemes, MIME/extensions, and max 25 MB size before processing. |
| T-19-02-02 | D | extraction pipeline | mitigate | Use guided retry/open/report actions and avoid silent retries that can loop indefinitely. |
| T-19-02-03 | R | duplicate decision branch | mitigate | Log and route explicit user intent (open existing vs add duplicate) with deterministic branch handling. |
</threat_model>
