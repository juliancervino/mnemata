> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

### Task 2: Refine Tiered Proxy Pipeline with Jina Reader

Add the `_fetchViaJinaReader` method to `ExtractionService`.

```dart
Future<String?> _fetchViaJinaReader(String url) async {
  try {
    _webLog('Attempting Jina Reader fallback for $url');
    final jinaUrl = 'https://r.jina.ai/${Uri.encodeComponent(url)}';
    final response = await _client.get(Uri.parse(jinaUrl));
    if (response.statusCode == 200) return response.body;
  } catch (e) {
    _webLog('Jina Reader failed: $e');
  }
  return null;
}
```
