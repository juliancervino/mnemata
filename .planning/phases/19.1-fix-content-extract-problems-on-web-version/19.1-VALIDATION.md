# Phase 19.1: Fix Content Extract Problems on Web Version - Validation

## Objective
Validate that the web version of Mnemata can reliably extract content from URLs and PDFs, bypassing CORS restrictions via proxies and providing a manual ingest fallback.

## Success Criteria
- [ ] `defuddle.js` (Obsidian Web Clipper engine) is correctly integrated and functional on the web platform.
- [ ] `ExtractionService` successfully uses raw proxies (`corsproxy.io`, `allorigins.win`) to fetch HTML on web.
- [ ] Metadata extraction (JSON-LD, OpenGraph) takes priority over DOM heuristics in the extraction pipeline.
- [ ] `PdfExtractionService` parses PDFs on web using byte buffers without crashing.
- [ ] `ManualIngestDialog` correctly uses `MnemataTheme` tokens and allows manual content entry.
- [ ] All new logic is covered by automated tests.

## Automated Verification

### 1. Service Tests
Run unit tests for extraction services to verify the tiered logic and byte handling.

```bash
# Verify tiered extraction pipeline
flutter test test/features/ingestion/services/extraction_service_test.dart

# Verify platform-agnostic PDF extraction
flutter test test/features/ingestion/services/pdf_extraction_service_test.dart
```

### 2. UI/Presentation Tests
Run widget tests for the manual ingest flow.

```bash
# Verify Manual Ingest Dialog
flutter test test/features/ingestion/presentation/manual_ingest_test.dart
```

### 3. Build Verification
Ensure the web build remains functional.

```bash
flutter build web --release
```

## Manual Verification (UAT)

### 1. Web URL Extraction
1. Launch the app on Web.
2. Enter a URL known to block direct fetches (e.g., `https://www.theverge.com`).
3. Confirm that content is extracted and displayed in the reader view.
4. Verify in browser dev tools that the request went through a proxy.

### 2. Web PDF Extraction
1. Launch the app on Web.
2. Upload/Share a PDF file.
3. Confirm that text is extracted and the ingestion summary is shown.

### 3. Manual Fallback
1. Trigger an extraction failure (e.g., by entering an invalid URL or disabling network).
2. Wait for the `IngestionFailureActionsSheet` to appear.
3. Select "Manual Ingest".
4. Paste some HTML into the dialog.
5. Confirm that the content is processed and displayed correctly.
