Fichero: lib/features/reader/presentation/reader_screen.dart
Comentario:
Calling `_saveHighlightFromText(text)` from `onPointerUp` can throw at runtime when the selected text can’t be located in `_plainContent` (e.g., due to whitespace/entity differences between HtmlWidget’s `selection.plainText` and `_extractPlainText`). In that case `_saveHighlightFromText` ends up attempting to write an invalid anchor (missing `start`/`end`), which `AnnotationService` rejects. Consider handling the “not found” case explicitly (don’t save + show feedback) or normalize/match text so valid offsets are always produced, and wrap the async save in error handling so pointer events don’t surface exceptions.
