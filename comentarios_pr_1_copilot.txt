Fichero: lib/features/ingestion/services/readability_platform_web.dart
Comentario:
`@JS('window.hasOwnProperty')` is not safe to call as a standalone function because `hasOwnProperty` depends on its `this` binding. When invoked without `window.` as the receiver it can throw and `_hasGlobal` may always fail. Use a receiver-safe check instead (e.g., `Reflect.has(window, prop)` via JS interop, or access the property and compare to `undefined`).
```suggestion
@JS('globalThis')
external JSObject get _globalThis;

@JS('Reflect.has')
external bool _reflectHas(JSObject target, String property);

bool _hasGlobal(String property) => _reflectHas(_globalThis, property);
```
